# The Flowers Box — Landing nueva

Proyecto estático listo para abrir o publicar.

## Abrir en local

Haz doble clic en `index.html` o usa Live Server en Visual Studio Code.

## Archivos

- `index.html`: estructura completa.
- `styles.css`: diseño y responsive.
- `script.js`: menú móvil, selección de producto y estado del formulario.
- `assets/images/`: fotografía principal y seis imágenes reales del catálogo.

## Antes de publicar

1. Conecta el formulario con Formspree o tu backend.
2. Sustituye textos, precios y nombres de productos si es necesario.
3. Añade las páginas legales.
4. Configura Stripe cuando el flujo de compra esté definido.
